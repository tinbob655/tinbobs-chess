# ♟️ Tinbob's Chess

A simple browser-based chess game where you can test your skills against a chess bot.

## Features

- Play chess against an AI opponent
- Clean, interactive board interface
- Standard chess rules enforced

## Getting Started

1. Clone or download the repository
2. Run the Vite frontend and the Java backend

## How to Play

- You play as **White** and always move first
- Click a piece to select it, then click a highlighted square to move
- The bot will respond automatically after your move
- The game ends when checkmate or a draw is reached
